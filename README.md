# المساعد البصري الذكي (Smart Vision Assistant)

تطبيق أندرويد مكتوب بلغة Kotlin، مصمم أساسًا للمكفوفين وضعاف البصر، ويعمل مع قارئات الشاشة مثل TalkBack وJieshuo Plus.

معرّف التطبيق: `com.mostafa.smartvision`

## الوظائف

ثلاث تبويبات رئيسية:

1. **الصور:** وصف الصور من الكاميرا أو المعرض بالذكاء الاصطناعي.
2. **المساعدة اليومية والكتابة:** مهام يومية وكتابة، مع قراءة ملفات PDF صفحة بصفحة أو كلها، ومحادثة متابعة عن النتيجة.
3. **الصوت:** تحويل النص إلى صوت بثلاثة محركات: Gemini، وGroq (نماذج Orpheus، العربية بلهجة سعودية، بحد 200 حرف للطلب فيقسّم التطبيق النص تلقائيًا)، ومحرك النظام. مع الموسيقى والمؤثرات والمزج.

## مزودو الذكاء الاصطناعي

- Gemini
- Groq

يدخل المستخدم مفتاح API الخاص به من شاشة الإعدادات. المفاتيح لا تُكتب في الكود ولا في المستودع أبدًا.

## الخصوصية وتخزين البيانات

- مفاتيح API تُحفظ على الجهاز مشفّرة بمفتاح محفوظ في Android Keystore، وخارج النسخ الاحتياطي.
- الصور والنصوص التي تطلب معالجتها تُرسل إلى المزود الذي اخترته فقط، عبر HTTPS. محرك صوت النظام يعمل على الجهاز دون إنترنت.
- الصور المؤقتة من الكاميرا تُحذف بعد تحليلها، ونسخ ملفات PDF المؤقتة تُحذف عند إغلاق الشاشة.
- يوجد في الإعدادات قسم للخصوصية يعرض ما هو مخزّن مؤقتًا ويمسحه بعد تأكيد منك، ويبلّغك بما حُذف وما تعذر حذفه.

## البناء

- المتطلبات: JDK 17، وGradle 8.10.2، وAndroid compileSdk 35 (minSdk 26).
- البناء الرسمي يتم على GitHub Actions عبر الملف `.github/workflows/build-apk.yml`، ويُنتج ملفين:
  - `SmartVisionAssistant-debug-apk`
  - `SmartVisionAssistant-release-apk` (الذي يُنصح باستخدامه)
- الأيقونات تُفك أثناء البناء من `.github/workflows/icons.zip`. لذلك البناء المحلي خارج GitHub Actions غير مدعوم حاليًا.

## التوقيع

- يوقَّع التطبيق بمفتاح ثابت هو الملف `app/smartvision-release.p12`، ويحميه كلمة سر طويلة عشوائية.
- كلمة السر محفوظة في سر GitHub Actions باسم `SV_KEY_PASSWORD`، ولا تُكتب في أي ملف.
- يجب عدم تغيير المفتاح بعد النشر، وإلا لن يقبل أندرويد التحديث فوق النسخ المثبتة.

## ترقيم الإصدارات

- `versionCode`: يساوي رقم تشغيل GitHub Actions، فيزيد تلقائيًا مع كل بناء. يجب ألا ينقص أبدًا.
- `versionName`: حاليًا `0.1-alpha`، وسيصبح `1.0.0` عند الإصدار المستقر.

## الاختبار

لا توجد اختبارات آلية حاليًا. نجاح البناء لا يعني أن كل الوظائف جُرّبت، وتجربتها تتم يدويًا على الجهاز. إضافة الاختبارات ضمن خطة الإصدار المستقر 1.0.
